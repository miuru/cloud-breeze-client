# Cloud Breeze Villa

Boutique-villa marketing and enquiry site built with Next.js 14, TypeScript and Tailwind CSS.

## Run locally

1. Install **Node 20 LTS** (or Node 18.17+). The current machine's Node 10 is not supported by Next 14.
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:3000`

Replace the clearly marked placeholder links, contact details, map iframe URL, images and review data in `data/` before launch.
